# InfraShape redesign (CZ) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Přestavět CZ stránku infrashape.vercel.app podle schválené specifikace a nasadit ve 3 etapách.

**Architecture:** Statický web (HTML/CSS/vanilla JS), nasazení push → GitHub `junmilan/infrashape` `main` → Vercel automaticky. Nové JS jako ES moduly (`<script type="module">`); čistá logika (listování, popup) v samostatných `*-logic.js` testovaných přes `node --test`, DOM vrstvy ověřené v náhledu prohlížeče.

**Tech Stack:** HTML5, CSS custom properties, ES modules, Lenis 1.1.13 (self-hosted), Node 24 `node:test`, Pillow (konverze obrázků), náhled `py -3 -m http.server` (launch config `infrashape`, port 8770).

**Spec:** `docs/superpowers/specs/2026-10-29-redesign-design.md`
